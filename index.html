03. Projects & Labs

VLAN Configuration Lab

Packet Tracer

Objective: Segment a small office network into VLANs to improve security and reduce broadcast traffic.

Switch(config)# vlan 10
Switch(config-vlan)# name SALES
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

💡 What I Learned: How VLANs isolate broadcast domains and improve network security.

Basic Router Configuration

Packet Tracer

Objective: Configure static routing between two separate networks.

Router(config)# interface g0/0

Router(config-if)# no shutdown

💡 What I Learned: How routers forward packets between different networks using interfaces and IP addressing.
